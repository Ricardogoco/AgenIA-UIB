# AgenIA

Últimamente tengo muchas cosas por hacer y se me olvida anotar cosas importantes como; Reuniones pendientes, pagos realizados que luego no recuerdo y desconfiguran mis cuentas, agendar un encuentro con fecha, alarma o recordatorio. son muchas cosas que quisiera poder controlar o simplemente contratar una asistente personal o organizadora de archivos, pero me es muy costoso y tampoco quisiera andar todo el tiempo con una persona al lado.

Crea una App movil que se llame AgenIA-UIB; que cumpla con las mismas funciones que tienen la App HiNoter y MonAi, donde se puedan manejar bien las finanzas personales y grabar reuniones mientras se sacan resumenes de los temas puntuales y cree mapas mentales de las reuniones, que tambien tenga una parte donde se gestione bien las deudas... etc 

que todo se pueda realizar tambien por medio de comando de voz y que trabaje en segundo plano, para las personas que no manejan muy bien las tecnologias
